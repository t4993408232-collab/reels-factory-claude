# Голос → ролик

Главный вывод нашего завода: **ролики с голосом с первой секунды досматривают, ролики «текст + музыка» — нет.** Этот скилл превращает 3 минуты на диктофон в готовый ролик.

## Нужно
- ffmpeg (с libass, обычно есть), Python 3.10+.
- Распознавание: `pip install mlx-whisper` (Mac на Apple Silicon) или `pip install faster-whisper`.
- Модель шумоподавления: `curl -L -o ~/.reels-factory/std.rnnn https://raw.githubusercontent.com/richardpl/arnndn-models/master/std.rnnn`.

## Запуск
```bash
python3 scripts/voice_reel.py запись.m4a --out reel.mp4 --accent ChatGPT Тьюринг \
    [--bg фон.mp4|фон.png] [--music музыка.mp3] [--mix 0.75]
```
- `--accent` — слова, которые подсветятся цветом (и подскажут распознаванию правильное написание).
- `--bg` — видео или картинка под субтитры (анимация, экран-демо, изометрия из `reels-iso-story`). Без него — тёмный градиент.
- `--music` — фон; громкость сама падает, когда звучит голос.
- `--mix` — сила шумоподавления 0–1. **0,75 по умолчанию.** На 1,0 голос телефона может стать «металлическим» — лучше записать заново на петличку, чем давить шум.

## Как записывать (подскажи человеку)
- Петличка (DJI и т. п.) на воротнике в 15–20 см ото рта, сбоку; шумоподавление на приёмнике — выкл.
- Комната с мебелью или шторами; 2 секунды тишины в начале.
- Читать живо и с иронией, первая фраза — сам хук, без «привет».

## Проверка перед публикацией
1. Вытащи 4–6 кадров (`ffmpeg -ss 3 -i reel.mp4 -frames:v 1 k.jpg`) и прочитай субтитры: термины (ChatGPT, Claude) написаны правильно?
2. Голос начинается на 0,0–0,3 с?
3. Длина 30–45 с для практики, до 60 с для истории.
